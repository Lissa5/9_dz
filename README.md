# Лабораторная работа № 9

## Условие задачи

Написать программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью заданного символа. Фигура — равносторонний треугольник, заполнение — только контур.

Пользователь задаёт параметр `a`, определяющий размер треугольника. Символ для построения фигуры задаётся в программе как константа.

## 1. Алгоритм и блок-схема

### Алгоритм

1. Начало программы.
2. Подключение необходимых библиотек.
3. Объявление переменных `a`, `i`, `j`.
4. Задание символа для рисования треугольника.
5. Ввод значения `a` с клавиатуры.
6. Проверка введённого значения. Если `a` меньше или равно нулю, вывести сообщение об ошибке и завершить программу.
7. Организация внешнего цикла, отвечающего за количество строк треугольника.
8. Вывод пробелов перед символами для формирования формы треугольника.
9. Организация внутреннего цикла для вывода символов.
10. Проверка условия вывода символа:
    - если строка последняя, выводится основание треугольника;
    - если символ первый или последний в строке, выводится боковая сторона;
    - в остальных случаях выводится пробел.
11. Переход к следующей строке.
12. Повторение действий до завершения внешнего цикла.
13. Конец программы.

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "Russian");

    int a;
    int i, j;
    char symbol = '*';

    printf("Введите размер треугольника: ");
    scanf("%d", &a);

    if (a <= 0)
    {
        printf("Ошибка! Размер должен быть положительным.\n");
        return 1;
    }

    for (i = 1; i <= a; i++)
    {
        for (j = 1; j <= a - i; j++)
        {
            printf(" ");
        }

        for (j = 1; j <= 2 * i - 1; j++)
        {
            if (i == a || j == 1 || j == 2 * i - 1)
            {
                printf("%c", symbol);
            }
            else
            {
                printf(" ");
            }
        }

        printf("\n");
    }

    return 0;
}
```

Также была проверена работа программы при вводе нулевого и отрицательного значения. В этих случаях программа выводит сообщение об ошибке.
